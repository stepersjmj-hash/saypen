# 세이펜 추출기 — PIN 음원 추출

세이펜 북 파일(.pin)을 넣으면 안에 들어 있는 MP3 음원을 꺼내 줍니다.
설치 없이 브라우저에서 바로 쓰며, 파일은 어디로도 전송되지 않습니다.

## 접속
- 웹: https://stepersjmj-hash.github.io/saypen/ ← 이 주소로 쓰는 것을 권장
- 휴대폰: 위 주소를 열고 사파리 "홈 화면에 추가" 또는 네이버 앱 바로가기 추가 → 세이펜 추출기 아이콘으로 등록됩니다
  (예전에 글자 아이콘으로 등록했다면 지우고 새로고침한 뒤 다시 추가)
- 또는 `index.html` 을 내려받아 크롬·엣지로 열기
  - 이렇게 PC 파일로 열고 받은 ZIP은 Windows가 "인터넷 보안 설정으로 인해 파일을 복사할 수 없습니다"
    라며 막습니다. ZIP 오른쪽 클릭 → 속성 → **차단 해제** 체크 후 압축을 푸세요.

## 화면 구성
- **상단바**: 로고 · 열린 파일 이름과 용량 · ☾/☀ 테마 전환 · **다른 파일** · **ZIP으로 저장 · n개**
- **왼쪽**: 보기 필터(전체 / 이름 없음 / 이름 붙임 / 삭제됨, 개수 표시) · 길이로 선택 · 파일 정보 · 단축키
- **가운데**: 음원 표 — 체크박스 · 번호 · 파일명 · 길이 · 용량 · ×
- **아래**: 재생 중일 때 나타나는 플레이어 바

## 사용법
1. `.pin` 파일을 화면에 끌어다 놓거나 클릭해서 선택 (예: `세계지도세이맵_64203_bk.pin`)
   - 작업 중에도 창 아무 곳에 새 파일을 끌어다 놓으면 바로 바뀝니다
2. 음원 줄을 **클릭** → 미리 듣기. 아래 플레이어 바에서 이전 / 재생·정지 / 다음, 진행 막대 클릭으로 원하는 위치로 이동
   - **처음부터 연속 재생**으로 차례로 듣기 (× 로 멈추고 닫기)
   - **Space** 로 재생·정지
3. 파일명을 **더블클릭** 또는 **F2** → 이름 입력. 플레이어 바의 제목을 더블클릭하거나 **✎** 를 눌러도 됩니다
   - Enter 또는 다른 곳 클릭: 저장 / Esc: 취소 / 빈칸으로 저장: 원래 번호로 되돌림
   - `.mp3` 는 자동으로 붙고, 파일명에 쓸 수 없는 문자(`\ / : * ? " < > |`)는 빠집니다
   - 같은 이름이 여러 개면 ZIP 안에서 `이름 (2).mp3` 처럼 번호가 붙습니다
   - 번호 열은 항상 원래 번호를 보여 주므로 이름을 바꿔도 순서를 알 수 있습니다
4. **보기 필터**로 원하는 것만 보기
   - **이름 없음**: 아직 이름을 붙이지 않은 음원만 — 이름을 붙이면 목록에서 바로 빠집니다
   - **이름 붙임**: 이름을 바꾼 음원만
   - **삭제됨**: 지운 음원 — 클릭해서 들어볼 수 있고 **↺** 로 하나씩 되살립니다
5. 필요 없는 음원은 오른쪽 **×** 를 눌러 삭제 → 목록·연속 재생·ZIP에서 빠집니다
   - **여러 개 한 번에**: 체크박스 클릭, 또는 하나를 클릭한 뒤 **Shift+클릭**(범위)·**Ctrl+클릭**(하나씩, 맥은 ⌘+클릭)
   - 표 머리의 체크박스, **전체 선택** 버튼, **Ctrl+A** → 지금 보기에 보이는 음원 모두 선택
   - **길이로 선택**(왼쪽): 시간을 넣고 Enter 또는 **선택** → 그 시간 이하인 음원을 모두 선택
     (`10` = 10초, `1:30` = 1분 30초. 표에 보이는 길이 기준이라 `0:10` 인 음원은 10 이하에 들어감). 이어서 **Delete** 로 한 번에 삭제
   - 선택하면 도구 막대 오른쪽에 **"n개 선택 · n개 삭제 · 해제"** 가 뜹니다. **Delete** 키로 지우고 **Esc** 로 해제
   - 잘못 지웠으면 **삭제 되돌리기** (지운 순서의 역순, 한 번에 지운 묶음은 한 번에 복구)
6. **ZIP으로 저장** → 남은 음원만 바꾼 이름 그대로 MP3들이 담긴 `<원본이름>_음원.zip` 저장

## 다크 모드
처음에는 컴퓨터(시스템) 설정을 따릅니다. 상단바 ☾/☀ 버튼으로 바꾸면 그 선택을 기억합니다.

## 참고
- 스티커 ↔ 음원 연결 정보는 암호화되어 있어 해석하지 않습니다. 들어보고 이름을 붙이세요.
- 세계지도 세이맵 파일 기준으로 분석한 구조라, 다른 .pin 파일은 추출되지 않을 수 있습니다.
- 추출한 음원은 출판사의 저작물입니다. 개인 소장·학습용으로만 사용하세요.
