# 🔊 세이펜 PIN 음원 추출기

세이펜 북 파일(.pin)을 넣으면 안에 들어 있는 MP3 음원을 꺼내 줍니다.
설치 없이 브라우저에서 바로 쓰며, 파일은 어디로도 전송되지 않습니다.

## 접속
- 웹: https://stepersjmj-hash.github.io/saypen/ ← 이 주소로 쓰는 것을 권장
- 또는 `index.html` 을 내려받아 크롬·엣지로 열기
  - 이렇게 PC 파일로 열고 받은 ZIP은 Windows가 "인터넷 보안 설정으로 인해 파일을 복사할 수 없습니다"
    라며 막습니다. ZIP 오른쪽 클릭 → 속성 → **차단 해제** 체크 후 압축을 푸세요.

## 사용법
1. `.pin` 파일을 화면에 끌어다 놓거나 클릭해서 선택 (예: `세계지도세이맵_64203_bk.pin`)
2. 추출된 음원 목록에서 **클릭** → 미리 듣기, **처음부터 연속 재생**으로 차례로 듣기
3. 파일명(번호)을 **더블클릭** → 이름 입력
   - Enter 또는 다른 곳 클릭: 저장 / Esc: 취소 / 빈칸으로 저장: 원래 번호로 되돌림
   - `.mp3` 는 자동으로 붙고, 파일명에 쓸 수 없는 문자(`\ / : * ? " < > |`)는 빠집니다
   - 같은 이름이 여러 개면 ZIP 안에서 `이름 (2).mp3` 처럼 번호가 붙습니다
4. **ZIP으로 저장** → 바꾼 이름 그대로 MP3들이 담긴 `<원본이름>_음원.zip` 저장

## 참고
- 스티커 ↔ 음원 연결 정보는 암호화되어 있어 해석하지 않습니다. 들어보고 이름을 붙이세요.
- 세계지도 세이맵 파일 기준으로 분석한 구조라, 다른 .pin 파일은 추출되지 않을 수 있습니다.
- 추출한 음원은 출판사의 저작물입니다. 개인 소장·학습용으로만 사용하세요.
